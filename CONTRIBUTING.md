# Contributing to chromatic-core

Thank you for your interest! 🎨

## Ways to Contribute

- 🐛 Report bugs
- 💡 Suggest features
- 📚 Improve docs
- 🌍 Translate
- 🎨 Add palettes

## Commit Convention

- feat: new feature
- fix: bug fix
- docs: documentation
- style: formatting
- refactor: refactoring
- perf: performance
- test: tests
- chore: maintenance

## Code Style

- HTML: Semantic HTML5, 2-space indent
- CSS: Custom properties, BEM naming
- JavaScript: Vanilla ES2022+, zero deps
